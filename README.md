# Karadel calc worker

Внешний воркер, который снимает с Lovable тяжёлый расчёт (распознавание
чертежа через Claude + заполнение Excel-шаблона). У него нет лимита 30 секунд,
поэтому он не зависает на больших чертежах.

## Как это работает

1. В Lovable менеджер жмёт «Запустить расчёт».
2. Lovable шлёт сюда `POST /process { order_id }` с секретным заголовком и
   сразу получает ответ `202` (за доли секунды).
3. Воркер в фоне: качает чертёж и шаблон из Supabase → Claude по чертежу →
   заполняет xlsx (правкой XML внутри zip, без потери выпадающих списков) →
   кладёт готовый файл в бакет `results` → ставит заказу статус `done`.
4. Lovable опрашивает статус и показывает готовый файл.

## Запуск на Railway (по шагам)

1. Залейте эти файлы в репозиторий (GitHub) или загрузите проект в Railway.
2. Railway → **New Project** → из репозитория. Он сам поймёт Python по
   `requirements.txt` и запустит командой из `Procfile`.
3. Railway → проект → **Variables** — добавьте переменные (НИКОГДА не в код):

   | Переменная | Значение |
   |---|---|
   | `ANTHROPIC_API_KEY` | ваш ключ Claude API |
   | `SUPABASE_URL` | URL вашего Supabase (из Lovable Cloud) |
   | `SUPABASE_SERVICE_ROLE_KEY` | service role key Supabase (полный доступ, только здесь!) |
   | `WORKER_SECRET` | придумайте длинную случайную строку |
   | `TEMPLATE_PATH` | путь активного шаблона в бакете `templates` (напр. `master.xlsx`) |
   | `CLAUDE_MODEL` | (необязательно) модель Claude; по умолчанию быстрая |
   | `MAX_PAGES` | (необязательно) сколько страниц PDF слать в Claude, по умолчанию 15 |

4. Дождитесь деплоя. Railway даст URL вида `https://...up.railway.app`.
5. Проверьте, что воркер жив: откройте `https://<ваш-url>/health` —
   должно вернуть `{"ok": true}`.

## Подключение к Lovable

В Lovable добавьте секреты `WORKER_URL` (тот URL с Railway) и `WORKER_SECRET`
(тот же пароль, что задали в Railway) и дайте Lovable промпт «звать воркер
вместо расчёта внутри себя» (он у вас уже есть в переписке).

## Что подогнать под вашу базу

Эти имена заданы вверху `main.py` в блоке КОНФИГ — поменяйте, если в вашей
схеме Supabase они другие:

- таблица заказов `orders` и колонки `id`, `status`, `processing_log`,
  `drawing_path`, `result_path`;
- бакеты хранилища `drawings`, `templates`, `results`.

## Что вставить обязательно

В `main.py` найдите `EXTRACTION_PROMPT` и вставьте туда ваш рабочий промпт
распознавания чертежа из Lovable (тот, что уже давал 25 позиций на тесте).
Требование одно: Claude должен вернуть **только JSON** в формате, описанном
рядом в комментарии.
